# Главная страница (CMS)

## Точка входа

Корневой [`/index.php`](../../../index.php) должен подключать `bitrix/routing_index.php` — модуль при установке патчит файл при необходимости.

## Инфоблоки (тип `myapp_catalog_main`)

| Код ИБ | Секция |
|--------|--------|
| `myapp_main_slider` | Верхний слайдер (элементы по SORT, свойства `LINK`, `CAPTION`, картинка — PREVIEW_PICTURE) |
| `myapp_main_advantages` | Преимущества (`ICON`, `TEXT`, NAME) |
| `myapp_main_about` | Один активный элемент «О нас» |
| `myapp_main_seo` | Один активный SEO-блок внизу страницы |

Настройки ID и маппинг полей — вкладка **Главная** в настройках модуля.

## Категории каталога на главной

- Берутся **корневые разделы** (`DEPTH_LEVEL = 1`) инфоблока каталога.
- Фильтр: UF **«Показывать на главной»** (`UF_SHOW_ON_MAIN` по умолчанию).
- Сортировка: `UF_MAIN_SORT`, затем `SORT`, `NAME`.
- Лимит: опция `home_sections_limit` (по умолчанию **4**).

UF создаются при установке/обновлении модуля для текущего `catalog_iblock_id`.

## Видимость секций

Чекбоксы `home_show_*` на вкладке **Главная** отключают блок без правки шаблона.

## Кеш

Сборка главной кешируется в `/myapp_catalog/home/`. Инвалидация при изменении элементов CMS-инфоблоков и разделов каталога.
